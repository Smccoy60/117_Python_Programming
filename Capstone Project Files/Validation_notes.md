## Project

Payroll Calculator and Report Generator

## Important Behavior Checked

**Payroll Calculation Accuracy** <br>
Verified that gross pay, deductions and net pay were calculated correctly using known values and manual calculations

**Input Validation** <br>
Tested blank employee IDs and names, negative numbers, and non-numeric input to ensure error messages displayed and the program required valid input.

**File Saving** <br>
Confirmed that payroll information was successfully written to the payroll_report.txt file and that the file contained the expected employee information and payroll results. 

**Multiple Employee Processing** <br>
Tested entering multiple employees and confirmed that hte program continued processing until the user selected not to add another employee. 

**Payroll Statistics Summary** <br>
Verified that employee count, total payroll, average payroll, highest pay, and lowest pay calculations displayed correctly. 

## Why These Checks Matter
These checks ensure the program produces accurate payroll calculations, prevents invalid user input, saves reports correctly, and provides reliable payroll statements. 

If any of these features fail, the program could generate incorrect payroll information or create incomplete reports.
