## Files

- EmployeewithEnhancements.py
- payroll_report.txt (created automatically)

## How To Run

Open PowerShell or VS Code terminal and navigate to the project folder. 

Run: <br>
python EmployeewithEnhancements.py

## What The Program Does

The program: <br>
- collects employee payroll information
- validates user input
- calculates regular pay, overtime pay, taxes, deductions, and net pay
- displays a payroll summary
- saves payroll information to a text file
- process multiple employees
- generates payroll statistics

## Sample Inputs

Employee ID: 1001
Employee Name: Sarah Imhoff
Regular Hours: 40
Hourly Rate: 25
Overtime Hours: 5
Federal Tax: 15
State Tax: 5
Insurance: 50
Retirement: 75

## Sample Outputs

The program displays: 
- Employee payroll summary
- Gross pay
- Total deductions
- Net pay

The program also saves payroll information to payroll_report.txt

## Notes

1. Employee ID and Name cannot be blank.
2. Hours and rates cannot be negative.
3. Invalid number entries display an error message.
4. The report file is automatically created if it does not already exist
