## Initial Plan

The original calculator would: <br>
- collect employee payroll information
- calculate payroll
- display payroll results 
- save a payroll report file

## What Reality Showed

As development of the program progressed, additonal improvements became achievable: <br>
- input validation was needed to prevent bad data
- multiple employee processing would make the program more realistic
- payroll statistics would provide useful summary information
- report files shoudl support storing more payroll records <br>

At the same time, advanced features such as databases, graphical interfaces, and tax table integration would have exceeded the project scope. 

## Revision
The final project included: <br>
- payroll calculations
- input validation 
- payroll report generation
- file output 
- multiple employee processing 
- payroll statistics summary

## Why This Is A Good Revision

1. The project remained manageable
2. the most useful payroll features were included
3. the program became more realistic
4. the code remained understandable and testable
