## 1. What I Built

**Project Name:** Payroll Calculator and Report Generator

**Purpose:** Create a Python program that collects employee payroll information, calculates payroll results, validates user input, saves reports, and produces payroll statistics.

## 2. Why I Chose It

I work in payroll and HR, so payroll calculations are something I work with regularly.  

I wanted a project that connected to my professional experience while allowing me to practice Python programming concepts learned throughout this course. 

## 3. How It Works

The program asks for: <br>
- Employee ID
- Employee Name
- Regular Hours
- Hourly Rate 
- Overtime Hours
- Federal Tax %
- Sate Tax %
- Insurance Deductions
- Retirement Deductions

The program then: <br>
- Calculates payroll
- Displays results
- Saves a payroll report
- Allows multiple employees to be processed
- Productes payroll statistics
